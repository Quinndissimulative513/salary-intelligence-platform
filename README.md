## 🔍 What this tool does

The platform organizes complex data into simple views for you. It performs several technical steps behind the scenes:

* Data Collection: It gathers raw information from salary records.
* Data Storage: It places that information into a structure called a star schema.
* Data Processing: It runs 125 unique SQL queries to sort the numbers.
* Intelligence: It applies six machine learning models. These models look for patterns in the data to categorize roles, predict pay levels, and flag unusual figures.
* Visualization: It connects this data to a 17-page report and a live dashboard.

## 📈 Understanding the features

You gain access to a digital dashboard that explains how salary benchmarks change.

* Regression analysis helps you see how different factors like location or job title shift the average pay.
* Segmentation groups similar roles together so you compare your data to relevant peers.
* The recommendation engine suggests areas where pay growth remains steady.
* Anomaly detection identifies data points that fall far outside typical ranges.
* The SHAP feature explains why the system makes certain predictions, so you see the logic behind the results.

## 🛠️ Frequently asked questions

Do I need to install Microsoft SQL Server or PostgreSQL?
No. The installer includes all necessary tools. You do not need to install extra software for the databases.

Will this software slow down my computer?
The application uses resources only when you open it. It does not run in the background when you close the window.

Can I export the data?
Yes. You can save the analysis results from the dashboard screen for your personal records.

What if the app does not open?
Check your internet connection first. Ensure you have the latest updates for your Windows system. If issues persist, delete the program and download the installer again from the release page.

## 🛡️ Privacy and data

The software processes local data files. It does not send your personal input to external servers unless you specifically use the update check feature. All statistical testing happens on your local hardware. This ensures you maintain control over your search criteria and results.
